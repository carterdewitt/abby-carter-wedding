# Carter and Abby’s Wedding

A responsive wedding website for Carter and Abby, with RSVP, calendar, photo gallery, and venue sections.

## Getting started

1. Run `npm install`.
2. Run `npx gulp` to compile Sass and minify JavaScript.
3. Open `index.html` in your browser.

Edit `index.html` for page content and `js/scripts.js` for calendar, sharing, and RSVP behavior. After JavaScript or Sass changes, run `npx gulp` again to update the files used by the page.

Set up your own hosting domain before adding a `CNAME` file.
